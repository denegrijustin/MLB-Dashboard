# MLB Dashboard ⚾

A production-quality Streamlit MLB dashboard featuring real-time game data, standings, spray charts, and home run tracking.

## Features

- **Kansas City Royals** as default team (team_id=118), all 30 MLB teams switchable
- **Logo-first UI** using MLB CDN SVG logos
- **Live Game State**: score, inning, status, linescore by inning
- **Standings**: all 6 divisions with team logos, W/L/PCT/GB/Streak
- **Player Impact**: broken down by role — Hitters, Starting Pitchers, Relievers, Closers
- **Spray Charts**: real Statcast batted-ball coordinates (hc_x, hc_y) with field overlay
- **Home Run Tracker**: real Statcast HR data with exit velo, distance, launch angle
- **Projected Record & Playoff Probability**: clearly labeled as model output

## Architecture

```
app.py              # Main Streamlit entry point
config.py           # All 30 team metadata, defaults, constants
sources/
  mlb_api.py        # MLB Stats API adapter (statsapi.mlb.com)
  statcast_api.py   # Baseball Savant Statcast adapter
services/
  live_game.py      # Live game detection and data
  standings.py      # Division/wildcard standings
  roster.py         # Roster with role classification
  player_impact.py  # Impact rankings by role
  spray_chart.py    # Spray chart from Statcast coords
  hr_tracker.py     # HR tracker from Statcast
  projections.py    # Projected record + playoff probability
utils/
  logos.py          # Logo URL helper
  formatting.py     # Formatters and helpers
views/
  landing.py        # Fast startup landing view
  live_game.py      # Live game tab
  standings.py      # Standings + playoff tab
  player_impact.py  # Player impact tab (4 roles)
  spray_charts.py   # Spray charts tab
  hr_tracker.py     # HR tracker tab
tests/
  test_sources.py   # API health + schema tests
  test_services.py  # Service transform tests
  test_defaults.py  # KC Royals default, logo fallback
```

## Data Sources

- **MLB Stats API**: `https://statsapi.mlb.com/api/v1` — live game data, standings, rosters
- **Baseball Savant (Statcast)**: `https://baseballsavant.mlb.com/statcast_search/csv` — batted ball events

## Spray Chart Coordinate System

Statcast uses `hc_x` (0–250, left→right from catcher view) and `hc_y` (0–250, home plate at top).  
Transform applied: `plot_x = hc_x - 125`, `plot_y = 200 - hc_y` to center field at top.

## Model Output Disclaimer

Playoff probability estimates are generated by a simple statistical model and are NOT official MLB projections.
